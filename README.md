# AI-Powered Story Generator

An AI-powered app that helps parents and caregivers create personalized stories to teach children aged 4–7 how to navigate everyday situations, emotions, and behaviours.

The repository includes a Claude Code project skill at `.claude/skills/delivery-assistant/SKILL.md` to support planning, issue triage, delivery check-ins, and documentation updates.

## Product focus

Caregivers describe or select an everyday situation, choose an age and optional character details, and receive an age-appropriate story with a learning objective. Child safety, caregiver control, and privacy are core product requirements.
